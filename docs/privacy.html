개인정보 처리방침

단어장 (Quiz Word) · iOS · Android · 시행일 2026년 11월 13일

이 앱은 개인정보를 수집하지 않습니다. 회원 가입이 없고, 서버로 아무것도 보내지 않으며, 광고·분석·추적 도구를 쓰지 않습니다. 학습 기록은 휴대폰 안에만 저장됩니다.

1. 수집하는 정보

없습니다. 앱은 이름, 이메일, 전화번호, 위치, 연락처, 기기 식별자, 사용 기록 등 어떤 개인정보도 수집하거나 개발자에게 전송하지 않습니다.

2. 기기 안에만 저장되는 정보

앱이 동작하려면 아래 정보가 필요하며, 모두 사용자의 기기 안에만 저장됩니다. 개발자를 포함한 누구에게도 전송되지 않습니다.

  • 학습 기록 — 단어별 복습 일정, 오답노트, 학습장, 하루 학습량
  • 설정 — 시험일, 하루 새 단어 수, 발음 목소리, 화면 테마 등
  • 사용자가 불러온 파일 — 단어 세트 파일, 시험 팩 파일

앱을 삭제하면 이 정보도 함께 삭제됩니다. 앱 안의 설정 → 진행 기록 → 기록 초기화로 학습 기록만 지울 수도 있습니다.

3. 사용자가 직접 하는 파일 주고받기

  • 내보내기: 설정 → 진행 기록 → 내보내기를 누르면 학습 기록을 JSON 파일로 만들어 시스템 공유 시트를 엽니다. 파일을 어디로 보낼지는 사용자가 고르며, 앱은 그 파일을 따로 전송하지 않습니다.
  • 가져오기·불러오기: 진행 기록, 단어 세트, 시험 팩은 사용자가 시스템 파일 선택기에서 고른 파일만 읽습니다. 앱이 다른 파일이나 사진에 접근하지 않습니다.

4. 같은 개발자의 다른 앱과 나누는 단어 목록

같은 개발자가 만든 문제은행 앱이 문제 속 단어를 표시할 수 있도록, 앱은 등록된 단어 목록(표제어·뜻·품사·발음기호·변화형)을 기기 안의 공유 위치(iOS App Group, Android 읽기 전용 ContentProvider)에 써 둡니다. 이 목록에는 학습 기록이나 개인정보가 들어 있지 않으며, 기기 밖으로 전송되지 않습니다.

5. 권한

  • 마이크: 사용하지 않습니다. iOS 앱 정보에 마이크 사용 설명 문구가 들어 있는 것은 발음 재생에 쓰는 오디오 모듈에 녹음 기능 코드가 포함되어 있어 Apple 이 문구를 요구하기 때문이며, 앱은 마이크 권한을 요청하지 않습니다.
  • 발음 듣기: 기기에 내장된 음성 합성(iOS AVSpeechSynthesizer, Android TTS)을 쓰며 인터넷 없이 동작합니다. 앱은 읽어 줄 단어를 외부 서버로 보내지 않습니다.
  • 위치, 카메라, 사진, 연락처, 알림, 추적(ATT) 권한을 요청하지 않습니다.

6. 외부 링크

설정의 시험 팩 만드는 법을 누르면 이 사이트(GitHub Pages)의 안내 페이지가 기기의 기본 브라우저로 열립니다. 그 페이지의 처리는 브라우저와 GitHub 의 개인정보 처리방침을 따릅니다.

7. 제3자 제공 · 광고 · 추적

개인정보를 수집하지 않으므로 제3자에게 제공하거나 처리를 위탁하는 일이 없습니다. 광고, 분석, 충돌 보고 SDK 를 쓰지 않으며 다른 회사의 앱·웹사이트에 걸친 추적을 하지 않습니다.

8. 아동의 개인정보

앱은 연령과 관계없이 어떤 개인정보도 수집하지 않습니다.

9. 방침의 변경

내용이 바뀌면 이 페이지를 고치고 위의 시행일을 바꿉니다. 앱이 정보를 수집하게 되는 변경이라면 앱 업데이트 전에 이 페이지에 먼저 알립니다.

10. 문의

개인정보 처리방침에 관한 문의는 GitHub Issues에 남겨 주세요. Issues 는 공개 게시판이므로 개인정보는 적지 마세요. 더 자세한 안내는 지원 페이지에 있습니다.

Privacy Policy

단어장 (Quiz Word) · iOS · Android · Effective November 13, 2026

This app does not collect any personal data. There is no account or sign-up, nothing is sent to a server, and no advertising, analytics or tracking SDKs are used. Your study progress stays on your device.

1. Information we collect

None. The app does not collect or transmit any personal information, such as name, email, phone number, location, contacts, device identifiers or usage data.

2. Information stored only on your device

  • Study progress — review schedule per word, mistakes list, notebooks, daily activity
  • Settings — exam date, new words per day, voice, theme
  • Files you import — word set files and exam pack files

This data never leaves your device. Deleting the app deletes it. You can also clear progress in Settings → 진행 기록 (Progress) → 기록 초기화 (Reset).

3. Files you choose to export or import

Exporting progress creates a JSON file and opens the system share sheet; you decide where it goes. Importing reads only the file you pick in the system file picker.

4. Word list shared with the developer's companion app

So that the developer's companion quiz app on the same device can highlight registered words, the app writes its word list (headwords, meanings, part of speech, pronunciation, word forms) to an on-device shared location (iOS App Group / Android read-only ContentProvider). It contains no progress or personal data and is never sent off the device.

5. Permissions

The app never requests microphone access. The iOS microphone usage description exists only because the bundled audio module (used to play pronunciations) contains recording APIs. Pronunciation uses the device's built-in speech synthesis and works offline. The app does not request location, camera, photos, contacts, notifications or tracking permission.

6. Third parties, ads and tracking

No personal data is collected, so none is shared with or sold to third parties. The app contains no ads and does not track you across other companies' apps or websites. The “how to make an exam pack” link opens this GitHub Pages site in your browser, which is subject to GitHub's privacy statement.

7. Changes and contact

If this policy changes, this page and its effective date will be updated. For questions, please open an issue on GitHub Issues (public — please do not include personal information).
