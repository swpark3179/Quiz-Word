단어장 지원

단어장(Quiz Word)은 시험 문제에 나온 영어 단어를 그 문제 속 문장과 함께 익히는 단어장 앱입니다. 가입 없이, 인터넷 없이 동작합니다.

문의하기 버그 제보, 단어 뜻·예문 오류, 기능 제안은 GitHub Issues 에 남겨 주세요. 앱 버전(설정 → 정보)과 기기 모델을 함께 적어 주시면 빨리 확인할 수 있습니다. Issues 는 공개 게시판이므로 개인정보는 적지 마세요.

자주 묻는 질문

회원 가입이나 인터넷 연결이 필요한가요?

아니요. 단어 데이터가 앱에 들어 있어 가입 없이, 오프라인에서 모든 기능을 쓸 수 있습니다. 학습 기록은 기기 안에만 저장됩니다.

다른 휴대폰이나 웹 버전으로 학습 기록을 옮기고 싶어요
  1. 원래 기기에서 설정 → 진행 기록 → 내보내기 — JSON 파일이 만들어지면 AirDrop·iCloud Drive·메신저 등으로 보냅니다.
  2. 새 기기의 파일 앱에 파일을 둔 뒤 설정 → 진행 기록 → 가져오기에서 고릅니다.

학습장 목록도 함께 옮겨집니다.

새 시험의 단어를 더하고 싶어요 (시험 팩)

시험 하나를 담은 시험 팩 파일(*.exampack.json)을 설정 → 시험 → 시험 팩 불러오기로 더할 수 있습니다. 이미 있는 단어와 다른 시험은 그대로 남습니다.

시험 팩을 만드는 방법과 파일 검사기는 시험 팩 안내 페이지에 있습니다. 추가한 시험은 설정 → 시험 목록에서 지울 수 있습니다.

단어 세트 파일은 무엇인가요?

앱의 단어 전체를 새 버전으로 바꾸는 파일입니다. 설정 → 단어 세트 → 파일에서 불러오기로 넣고, 언제든 앱 기본 단어 세트로 되돌리기로 돌아갈 수 있습니다. 진행 기록은 단어 기준이라 그대로 이어집니다.

발음이 들리지 않거나 목소리가 어색해요
  • 기기 음량을 확인해 주세요. 무음 모드에서도 발음은 들리도록 되어 있습니다.
  • 더 자연스러운 목소리는 iPhone 설정 앱 → 손쉬운 사용 → 읽기 및 말하기 → 음성에서 영어 고품질 음성을 내려받은 뒤, 앱 설정 → 발음 → 목소리에서 고르면 됩니다.
복습 일정은 어떻게 정해지나요?

FSRS 간격 반복 알고리즘으로, 아는 단어는 간격을 넓히고 모르는 단어는 자주 보여 줍니다. 설정 → 학습 → 시험일을 정하면 복습 간격이 시험일을 넘지 않아 시험 전에 모든 단어를 한 번 더 봅니다.

학습 기록을 지우고 싶어요

설정 → 진행 기록 → 기록 초기화로 지울 수 있습니다. 앱을 삭제해도 기기 안의 기록이 모두 지워집니다.

개인정보를 수집하나요?

수집하지 않습니다. 자세한 내용은 개인정보 처리방침을 보세요.

Support

단어장 (Quiz Word) is a vocabulary app for learning the English words that appear in exam questions, together with the sentences they appear in. It works offline and needs no account.

Contact For bug reports, content corrections or feature requests, please open an issue on GitHub. Including the app version (Settings → 정보) and your device model helps. Issues are public, so please do not include personal information.
Open a GitHub issue
  • Move progress to another device: Settings → 진행 기록 → 내보내기 (Export), then 가져오기 (Import) on the other device.
  • Add an exam: Settings → 시험 → 시험 팩 불러오기 (Import exam pack). See the exam pack guide.
  • Reset progress: Settings → 진행 기록 → 기록 초기화.
  • Privacy: the app collects no personal data — see the privacy policy.
