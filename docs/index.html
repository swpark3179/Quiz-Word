Quiz Word 시험 팩

시험 문제 파일에서, Quiz Word 앱에 새 시험만 따로 얹을 수 있는 파일(시험 팩)을 만드는 방법입니다. 앱에 이미 있는 단어와 다른 시험은 그대로 두고 더해집니다.

파일

  • exam-pack-guide.md에이전트용 가이드 — 형식, 작성 절차, 허용값, 완성 예시
  • validate-exampack.mjs검증기 (Node 18+, 의존성 없음) — 앱이 쓰는 검사와 같은 코드
  • exampack.schema.jsonJSON Schema — 구조·필수 필드·허용값
  • example.exampack.json검증기를 통과하는 작은 완성 예시
  • llms.txt에이전트용 길잡이

만드는 순서

  1. 코딩 에이전트에게 문제 파일과 아래 지시문을 줍니다.
  2. 에이전트가 <시험 id>.exampack.json 을 만들고 검증기를 통과시킵니다.
  3. 받은 파일을 아래 검증기에 넣어 한 번 더 확인합니다.
  4. iPhone 앱: 파일을 폰으로 옮긴 뒤 설정 → 시험 → 시험 팩 불러오기.
    웹(저장소): npm run data:add-pack <파일>

에이전트에게 줄 지시문

이 폴더의 문제 파일로 Quiz Word 시험 팩을 만들어 줘.

1. 가이드를 처음부터 끝까지 읽고 그대로 따라 줘:
   https://swpark3179.github.io/Quiz-Word/exam-pack-guide.md
2. 시험 id: (예: my-exam) / 시험 이름: (예: 내 시험)
3. 결과는 파일 하나: <시험 id>.exampack.json
4. 검증기를 받아서 돌리고, RESULT: PASS 가 나올 때까지 고쳐 줘:
   curl -fsSLO https://swpark3179.github.io/Quiz-Word/validate-exampack.mjs
   node validate-exampack.mjs <시험 id>.exampack.json
5. 마지막에 검증기 출력(경고 포함)과, 넣지 않은 낱말의 기준을 알려 줘.

검증기

시험 팩 파일을 넣으면 앱이 불러올 수 있는지 바로 확인합니다. 파일은 이 브라우저 안에서만 읽고 어디에도 보내지 않습니다.

명령줄에서는 node validate-exampack.mjs <파일> — 종료 코드 0 통과 · 1 오류 · 2 파일을 읽지 못함.
