## 문제 1
### **The agent should escalate the ticket when the quota is exceeded. Which action is best?**

| 보기 | 설명 |
|---|---|
| ① Retry the request and hope the quota resets | 재시도 |
| **②** Escalate the ticket to a human reviewer | 넘기기 |
| ③ Ignore the quota | 무시 |

**정답: ②**
**해설:**
> 📝 문제 번역
- 할당량을 넘으면 에이전트는 티켓을 넘겨야 한다. 어떤 조치가 가장 좋은가?
- ① 요청을 다시 시도하고 할당량이 초기화되기를 바란다
- ② 티켓을 사람 검토자에게 넘긴다
- ③ 할당량을 무시한다

> **핵심** 한도를 넘으면 사람에게 넘긴다.
