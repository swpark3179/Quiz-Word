# 생성 B — 문제 문장 한글 해석

영어 시험 문제(Claude Certified Architect — 에이전트·도구·프롬프트·Claude Code 주제)의 문장을 한국어로 옮긴다. 단어장 앱에서 예문 아래 해석으로 보여 준다.

## 입력
JSON 배열. 항목마다 `{ key, koRef, sentences: [{sid, en}] }`.
- `koRef`: 그 문제 전체(본문 + 보기 ①②③④)의 기존 한글 번역. **문장 단위로 쪼개 쓸 참고본**이다.
- `sentences`: 해석할 영어 문장들 (문제 본문을 문장으로 나눈 것, 가끔 보기 문장).

## 출력
`{ "<sid>": "<한글 해석>", ... }` 형태의 JSON 객체 하나. 입력의 모든 sid 를 빠짐없이 포함한다.

## 규칙
- `koRef` 에 해당 문장의 번역이 있으면 **그 표현을 최대한 그대로** 가져와 문장 하나 분량으로 잘라 쓴다(용어 일관성). 없거나 맞지 않으면 직접 자연스럽게 번역한다.
- 영어 문장 하나 = 한글 문장 하나. 앞뒤 문장 내용을 끌어오지 않는다.
- 인라인 코드(`` `...` ``), 파일명, 도구 이름, 고유명사(Claude, CLAUDE.md, MCP 등)는 원문 표기를 유지한다.
- `[Scenario: X]` 문장은 `[시나리오: X의 한글 번역]` 으로.
- 해요체가 아닌 문제 번역의 문체(…합니다 / …한다)를 따른다.

## 출력 방법
- 지정된 출력 파일에 Write 도구로 유효한 JSON 객체 하나만 저장한다(코드 펜스 없이).
- 저장 후 `node -e "const o=JSON.parse(require('fs').readFileSync('<출력파일>','utf8'));console.log(Object.keys(o).length)"` 로 개수를 확인한다.
- 마지막 응답은 한 줄: `완료 <출력파일> <개수>개`.
